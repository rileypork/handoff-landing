API and MCP for agents

Handoff’s product is the authenticated Delivery API. MCP is a thin tool wrap over the same /v1 jobs. This page is public and marketing-safe. Live hosts and keys are sent privately after access.

Not a consumer app. There is no booking form, checkout, or live pricing here. Quotes and jobs run through /v1.

Get access

  1. 01

    Request access

    Email handoff@agentmail.to or use the request form.

  2. 02

    Receive a private key

    Ops mints an opaque account-scoped key and sends it privately. Do not put keys in frontend env.

  3. 03

    Call the product

    Use /v1 directly, or connect MCP tools once you have a key and the private base URL.

Tools

Marketing names first. After access, the same four jobs exist on REST and MCP.

Job What it does
quote Ask Handoff for a haul quote. Pricing comes from the API, not this site.
create Book a delivery after a quote. Use an idempotency key on create.
observe Read delivery status and events.
cancel Request a cancellation on an open job.

This landing does not proxy /v1. It does not publish seed keys, peppers, or private base URLs.
